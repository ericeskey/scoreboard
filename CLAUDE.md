# Project instructions

## Copy standards (apply without being asked, every time)

Run every line through these before writing it, not after being corrected.

1. **No throat-clearing.** Never write about the document, the reader, or the act of communicating. Cut: "written for you," "in answer to your question," "three questions, none of them rhetorical," "this is the cheapest moment to say so," "the sentence is below," "worth more than an approved one." If a sentence would still be true with the subject removed, it is throat-clearing.
2. **No self-reference.** The document does not refer to itself, its own structure, or its own honesty. Cross-references name a page and stop ("page 2 lists them").
3. **Say things plainly, in natural language.** Say what is true in the shortest ordinary words. No aphorism where a sentence will do. No writerly turns, no rule-of-three flourishes.
4. **Questions take question marks.** A question dressed as a statement reads as evasion.
5. **No dangling blocks.** Every block earns its place and connects to the one before it. If a section has no destination or no reason to be read, cut it.
6. **Editorial Signal punctuation holds:** no em dashes, no exclamation marks, curly quotes, ALL CAPS only for eyebrows and display.
7. **Signal red is for the one thing we want the reader to do.** Emphasis inside prose is bold ink, not accent.

Run THE-TELL pass on every draft before showing it.
