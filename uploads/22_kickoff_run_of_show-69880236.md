## Day 2: Snapshots at the source

**Morning: extraction and semantics.**
- Remaining snapshots pulled together, at the source, owners in the room.
- Definition confirmation per field that matters: what does this field mean, who fills it, when (source owners confirm material definitions, per the SOW).

**Afternoon: the 20-project trace.**
- Hand-trace projects end to end: record → impacted SKU → part number → SAP. Time each step, note each judgment call.
- This is the financial path tested with evidence. Whatever fraction traces cleanly is the honest baseline the reachability map reports.

*Day 2 output: snapshot set complete + confirmed; trace-sample results; the raw material of reachability map v1.*

## Day 3 (optional but recommended): First-pass mapping

**Morning: measures from decisions, then the twelve.**
- Decision-first hypothesis block (~45 min): per corrected decision inventory item, "What if we asked: what would this room need to see to make this decision significantly better?" Capture candidate measures with no reference to the existing list.
- Then the rapid pass: the twelve, plus any new candidates just hypothesized, against the terrain: reachable now / reachable with a defined step / blocked and why, per candidate, with Andreas's read live.
- Decision-inventory mapping: which candidates (original or new) inform which decisions; decisions left underserved flagged explicitly.

**Afternoon: close-out.**
- What we saw; what surprised us; what the mockup will show first.
- Working rhythm confirmed: the standing 6-9 am AZ / 9-noon PA / 2-5 pm Ireland window.

*Day 3 output: reachability map skeleton; mockup v1 direction; every week-1 SOW output either done or in motion, days early.*
